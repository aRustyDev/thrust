# compat-inventory

The static inventory of the Plane internal API that spike 0009 (desk half) ran against the Plane fork: Django URL
confs read with `ast`, React/TypeScript call sites, the join between them, the `FEATURES.md` tags and the effort
model. Its pinned output, `out-pinned/endpoint-inventory.csv`, is the current F-X13 acceptance list. Method and
numbers: [`research/0003-compat-plane-inventory.md`](../../.agents/plans/contrail/research/0003-compat-plane-inventory.md).

This is tooling, not product code. No crate imports it (ADR-0006 register, round 29).

## Running it

Python is run through `uv` only. Every script carries a PEP 723 header (`requires-python = ">=3.11"`,
`dependencies = []`) and uses the standard library only, so there is no `pyproject.toml` and no lock file to keep.

```sh
uv run tools/compat-inventory/run_all.py --root <plane tree root> --out <output dir>
```

`--features` defaults to `.agents/plans/contrail/FEATURES.md`. `--out` defaults to `tools/compat-inventory/out/`,
which is ignored by git. The pre-pin output (`300c2009d4`) is not committed: it is regenerated by running
`run_all.py` against that tree.
