# Worked example: one module, end to end

A small TypeScript module ported through the stages. The TS produced the fixtures and the Rust replayed them, and
the library passes the gate lints from `anti-patterns.md`
`[verified: node v26.9.0, rustc 1.98.1, clippy 0.1.98, serde 1.0.229, serde_json 1.0.154, thiserror 2.0.21]`.

## Stage 1: scope

Slice: `parseIssue` (validate untrusted input) and `rank` (sort). Decision per slice: `parseIssue` **adapt**
(validation tightened in two places; one branch **deferred**: an array or object `priority`, which JS would
stringify, returns an explicit error instead of being ported), `rank` **adapt** (collation cannot be reproduced
exactly). Nothing dropped.

## The TypeScript original

```ts
export type Priority = "urgent" | "high" | "medium" | "low" | "none";
const ORDER: Record<Priority, number> = { urgent: 0, high: 1, medium: 2, low: 3, none: 4 };
export interface Issue { id: string; name: string; priority: Priority; assignee?: string | null; estimate?: number }

export function parseIssue(raw: unknown): Issue {
  if (typeof raw !== "object" || raw === null) throw new TypeError("issue must be an object");
  const r = raw as Record<string, unknown>;
  if (typeof r.id !== "string" || r.id === "") throw new TypeError("id must be a non-empty string");
  if (typeof r.name !== "string") throw new TypeError("name must be a string");
  const priority = r.priority ?? "none";
  if (typeof priority !== "string" || !(priority in ORDER)) throw new RangeError(`unknown priority: ${String(priority)}`);
  if (r.estimate !== undefined && (typeof r.estimate !== "number" || Number.isNaN(r.estimate)))
    throw new TypeError("estimate must be a number");
  return { id: r.id, name: r.name.trim(), priority: priority as Priority,
           assignee: r.assignee as string | null | undefined, estimate: r.estimate as number | undefined };
}

export function rank(issues: Issue[]): Issue[] {
  return [...issues].sort((a, b) => ORDER[a.priority] - ORDER[b.priority] || a.name.localeCompare(b.name));
}
```

## Stage 2: freeze

27 cases through the lossless encoder in `freeze-and-oracle.md`, fixtures written before any Rust (the fixture
file is generated by that script and is not shipped). The cases: `minimal`, `trims_ascii_spaces`,
`trims_nbsp_and_em_space`, `trims_bom_zwnbsp`, `keeps_nel_u0085`, `assignee_null`, `assignee_string`,
`assignee_number`, `estimate_zero`, `estimate_above_2_53`, `priority_missing_defaults_none`,
`priority_null_defaults_none`, `priority_unknown`, `priority_inherited_key_constructor`, `priority_number`,
`priority_array`, `empty_id`, `name_not_string`, `estimate_string`, `raw_null`, `raw_array_is_object`, then for
`rank`: `rank_by_priority`, `rank_ties_by_name`, `rank_case_ties`, `rank_accents`, `rank_empty`,
`rank_stability_interleaved_60` (60 items, interleaved duplicate keys). What the freeze **discovered** (none of
it visible in the types):

| Case | TS behaviour |
|---|---|
| `priority_inherited_key_constructor` | `"constructor" in ORDER` is true, so `priority: "constructor"` is **accepted** |
| `trims_bom_zwnbsp` / `keeps_nel_u0085` | `trim()` removes U+FEFF and keeps U+0085 (Rust's `trim()` does the opposite) |
| `raw_array_is_object` | an array passes the object check and fails on `id` instead |
| `assignee_number` | the `as` cast never checks `assignee`, so `assignee: 5` is accepted |
| `priority_array` | `String(["a","b"])` is `a,b`, so the error reads `unknown priority: a,b` |
| `rank_accents` | ICU collation puts `ä` between `a` and `b` |
| `rank_stability_interleaved_60` | the sort is stable |

## Stages 3 and 4: the port

```rust
use serde::{Deserialize, Serialize};
use serde_json::{Map, Value};
use std::cmp::Ordering;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Priority {
    Urgent, High, Medium, Low,
    #[serde(rename = "none")]
    NoPriority, // not `None`: that would shadow Option::None in patterns
}
impl Priority {
    fn rank(self) -> u8 {
        match self { Priority::Urgent => 0, Priority::High => 1, Priority::Medium => 2,
                     Priority::Low => 3, Priority::NoPriority => 4 }
    }
    fn parse(s: &str) -> Option<Self> {
        match s {
            "urgent" => Some(Priority::Urgent), "high" => Some(Priority::High),
            "medium" => Some(Priority::Medium), "low" => Some(Priority::Low),
            "none" => Some(Priority::NoPriority), _ => None,
        }
    }
}

/// TS: `assignee?: string | null`. Three states, so `Option<Option<String>>`.
fn double_option<'de, T, D>(d: D) -> Result<Option<Option<T>>, D::Error>
where T: Deserialize<'de>, D: serde::Deserializer<'de> {
    Option::<T>::deserialize(d).map(Some)
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Issue {
    pub id: String,
    pub name: String,
    pub priority: Priority,
    #[serde(default, deserialize_with = "double_option", skip_serializing_if = "Option::is_none")]
    pub assignee: Option<Option<String>>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub estimate: Option<f64>,
}

/// TS threw TypeError / RangeError; the messages are observable, so both are kept.
#[derive(Debug, thiserror::Error, PartialEq)]
pub enum ParseError {
    #[error("{0}")] Type(String),
    #[error("{0}")] Range(String),
}
impl ParseError {
    pub fn js_name(&self) -> &'static str {
        match self { ParseError::Type(_) => "TypeError", ParseError::Range(_) => "RangeError" }
    }
}

/// ECMAScript `String.prototype.trim` set: Rust's White_Space minus U+0085, plus U+FEFF.
fn is_js_space(c: char) -> bool { (c.is_whitespace() && c != '\u{85}') || c == '\u{FEFF}' }

pub fn parse_issue(raw: &Value) -> Result<Issue, ParseError> {
    let empty = Map::new();
    let obj = match raw {
        Value::Object(m) => m,
        Value::Array(_) => &empty, // a JS array is an object whose fields are all undefined
        _ => return Err(ParseError::Type("issue must be an object".into())),
    };
    let id = match obj.get("id") {
        Some(Value::String(s)) if !s.is_empty() => s.clone(),
        _ => return Err(ParseError::Type("id must be a non-empty string".into())),
    };
    let name = match obj.get("name") {
        Some(Value::String(s)) => s.trim_matches(is_js_space).to_string(),
        _ => return Err(ParseError::Type("name must be a string".into())),
    };
    let priority = match obj.get("priority") {
        None | Some(Value::Null) => Priority::NoPriority, // JS: `?? "none"`
        Some(Value::String(s)) => Priority::parse(s)
            .ok_or_else(|| ParseError::Range(format!("unknown priority: {s}")))?,
        Some(v @ (Value::Number(_) | Value::Bool(_))) => {
            return Err(ParseError::Range(format!("unknown priority: {v}")))
        }
        // deferred: JS stringifies arrays/objects; an array is frozen as `priority_array`, an object is not; neither is ported
        Some(Value::Array(_) | Value::Object(_)) => {
            return Err(ParseError::Range("unknown priority: [unsupported]".into()))
        }
    };
    let estimate = match obj.get("estimate") {
        None => None,
        Some(Value::Number(n)) => n.as_f64(),
        Some(_) => return Err(ParseError::Type("estimate must be a number".into())),
    };
    let assignee = match obj.get("assignee") {
        None => None,
        Some(Value::Null) => Some(None),
        Some(Value::String(s)) => Some(Some(s.clone())),
        // TS cast `as string | null | undefined` never checked this; the port does.
        Some(_) => return Err(ParseError::Type("assignee must be a string or null".into())),
    };
    Ok(Issue { id, name, priority, assignee, estimate })
}

fn name_cmp(a: &str, b: &str) -> Ordering {
    // Approximation of ICU `localeCompare`: case-insensitive, lower case first on ties.
    a.to_lowercase().cmp(&b.to_lowercase()).then_with(|| b.cmp(a))
}

pub fn rank(issues: &[Issue]) -> Vec<Issue> {
    let mut v = issues.to_vec();
    v.sort_by(|a, b| a.priority.rank().cmp(&b.priority.rank()).then_with(|| name_cmp(&a.name, &b.name)));
    v // sort_by is stable, like Array.prototype.sort since ES2019
}
```

## Stage 5: verify (the replay with its controls)

```rust
use issue_rank::{parse_issue, rank, Issue};
use serde_json::Value;

/// Deliberate differences from the TypeScript original. Each needs a reason.
/// A case listed here MUST still differ: if it starts matching, the exception is stale and the test fails.
const EXCEPTIONS: &[(&str, &str)] = &[
    ("priority_inherited_key_constructor", "TS `in` accepted a key inherited from Object.prototype; Rust rejects it"),
    ("rank_accents", "ICU collation is not reproduced; Rust orders by lower-cased code point"),
    ("assignee_number", "TS cast never checked assignee; Rust rejects a value that is neither string nor null"),
    ("priority_array", "deferred branch: JS stringifies an array priority; Rust returns a fixed message"),
];

fn load() -> Value {
    let p = concat!(env!("CARGO_MANIFEST_DIR"), "/fixtures/issue_rank.json");
    serde_json::from_str(&std::fs::read_to_string(p).expect("fixture file")).expect("fixture json")
}

/// The encoder writes JS `undefined` as {"$":"undefined"}; on the JSON wire that is an absent key.
fn dec(v: &Value) -> Value {
    match v {
        Value::Object(m) => Value::Object(
            m.iter()
                .filter(|(_, x)| **x != serde_json::json!({"$": "undefined"}))
                .map(|(k, x)| (k.clone(), dec(x)))
                .collect(),
        ),
        Value::Array(a) => Value::Array(a.iter().map(dec).collect()),
        other => other.clone(),
    }
}

fn same(a: &Value, b: &Value) -> bool {
    match (a, b) {
        (Value::Number(x), Value::Number(y)) => x.as_f64() == y.as_f64(),
        (Value::Object(x), Value::Object(y)) => {
            x.len() == y.len() && x.iter().all(|(k, v)| y.get(k).is_some_and(|w| same(v, w)))
        }
        (Value::Array(x), Value::Array(y)) => x.len() == y.len() && x.iter().zip(y).all(|(p, q)| same(p, q)),
        _ => a == b,
    }
}

/// Returns one line per failing case; empty means the replay held.
fn replay(fixture: &Value) -> Vec<String> {
    let mut failures = vec![];
    let mut used_exceptions = vec![];
    for case in fixture["cases"].as_array().expect("cases") {
        let name = case["name"].as_str().expect("name");
        let arg = dec(&case["args"][0]);
        let got: Result<Value, (String, String)> = if name.starts_with("rank_") {
            let issues: Vec<Issue> = serde_json::from_value(arg).expect("rank input");
            Ok(serde_json::to_value(rank(&issues)).expect("serialise"))
        } else {
            parse_issue(&arg)
                .map(|i| serde_json::to_value(i).expect("serialise"))
                .map_err(|e| (e.js_name().to_string(), e.to_string()))
        };
        let matches = match (&got, case.get("ok"), case.get("throws")) {
            (Ok(v), Some(want), _) => same(v, &dec(want)),
            (Err((n, m)), _, Some(t)) => t["name"] == *n && t["message"] == *m,
            _ => false,
        };
        let excepted = EXCEPTIONS.iter().position(|(n, _)| *n == name);
        match (matches, excepted) {
            (true, None) | (false, Some(_)) => {}
            (false, None) => failures.push(format!("{name}: port differs from the frozen TypeScript behaviour")),
            (true, Some(_)) => failures.push(format!("{name}: stale exception, the port now matches")),
        }
        used_exceptions.extend(excepted);
    }
    for (i, (n, _)) in EXCEPTIONS.iter().enumerate() {
        if !used_exceptions.contains(&i) {
            failures.push(format!("{n}: exception names a case that does not exist"));
        }
    }
    failures
}

#[test]
fn port_matches_frozen_suite() {
    let f = load();
    assert_eq!(f["cases"].as_array().unwrap().len(), 27, "suite changed size: a gate that checks less proves less");
    assert_eq!(replay(&f), Vec::<String>::new());
}

#[test]
fn control_a_mutated_fixture_must_fail() {
    let mut f = load();
    f["cases"][0]["ok"]["priority"] = Value::String("high".into()); // `minimal` really returns "none"
    assert!(!replay(&f).is_empty(), "the replay did not notice a changed fixture; it proves nothing");
}
```

The full suite adds a second control that changes one expected error message and requires a failure (control 2 in
`freeze-and-oracle.md`). Results: the tests pass; the mutated-fixture control reports `minimal: port differs from
the frozen TypeScript behaviour`; seven hand-made mutants of the port were each caught at the intended case.

## Stage 5 continued: the exception register for this slice

| Case | Difference | Reason | Revisit |
|---|---|---|---|
| `priority_inherited_key_constructor` | Rust rejects `"constructor"` | TS bug (`in` sees the prototype chain); fixing it is intended | never, unless a caller depends on it |
| `rank_accents` | `ä` sorts after `z` | ICU collation is not reproduced | when an explicit collation policy is chosen |
| `assignee_number` | Rust rejects a non-string, non-null `assignee` | the TS cast never checked it; the tightening is intended | never |
| `priority_array` | message is `unknown priority: [unsupported]` | deferred branch (see the ledger) | when a caller sends an array priority |

## Stage 6: anti-pattern gate

The lint command in `anti-patterns.md` exits 0 on the port. Those lints also fire in test code (indexing a
`Value`, `unwrap`), so the gate runs on library targets only `[verified: clippy 0.1.98]`.
