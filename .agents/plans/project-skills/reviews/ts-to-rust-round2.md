## Findings
1. MEDIUM: the wildcard-only guard is bypassable and the doc overstates it: `_wild_only` strips only `*` and `/`, but `fnmatch` also treats `?` and `[seq]` as wildcards; `/?*`, `/[!x]*`, `*?*` are accepted and match every `/field` path (incl. `/status`), so `{"case":"c","path":"/?*"}` swallows all differences for case c (never stale; run still prints RESULT PASS). The docs say only `*` is special. Fix: a `*`-only matcher (`re.fullmatch(".*".join(map(re.escape, pat.split("*"))), s)`) or extend `_wild_only` to strip `?[]!^-` and require a literal character; add a selftest for `/?*` expecting exit 2. (oracle_diff.py:85-86, 99-100; docstring :20-23; freeze-and-oracle.md:131-133.)
2. LOW-MED: an HTTP-status difference shares the path `/status` with a body field named `status`: report HTTP status at a reserved path (e.g. `#status`), document it, add a selftest (oracle_diff.py:127-128, 136-137).
